# ExpertOption Analyzer

محلل فني عربي مستقل، مخصص للاختبار التجريبي وتحليل الأسواق.

## المميزات
- مؤشرات EMA 5 و EMA 13
- مؤشر RSI 7
- تحليل الزخم Momentum
- إشارات CALL و PUT و WAIT
- سجل الإشارات ونتائج الاختبار
- واجهة عربية متوافقة مع الآيفون

## وضع التشغيل
يعمل المشروع في الوضع التجريبي فقط إلى حين توفير مصدر أسعار مصرح به.

## تنبيه
لا يتصل هذا المشروع بحساب التداول ولا ينفذ صفقات حقيقية.
البيانات التجريبية ليست أسعار OTC حقيقية.
الإشارات ليست ضماناً للربح أو توصية مالية.
