# ExpertOption Analyzer

محلل فني عربي مستقل للاختبار التجريبي وتحليل الأسواق.

## مصدر الأسعار الحالي
- موصل WebSocket مدمج مع Twelve Data: `wss://ws.twelvedata.com/v1/quotes/price`.
- المصدر يعرض أسعار السوق الحقيقي (Real Market)، وليس أسعار OTC الخاصة بـ ExpertOption.
- لا يوجد حالياً مصدر OTC موثق لـ ExpertOption في هذا المشروع؛ لا يجوز تسمية أسعار مزود آخر بأنها ExpertOption OTC.
- يتطلب الاتصال API key من حساب Twelve Data. أدخل المفتاح وقت التشغيل فقط؛ لا تضعه في GitHub أو داخل الملف.
- التطبيق يطلب فحص 10 رموز: الذهب XAU/USD، أزواج EUR/USD وGBP/USD وUSD/JPY وUSD/CHF وAUD/USD، ومؤشرات DJI وNDX وSPX وDAX. أسماء المؤشرات تحتاج تأكيد توفرها من استجابة المزود، ولا يفترض التطبيق أنها متاحة.
- خطة Twelve Data Basic المجانية محدودة بتجربة WebSocket لحد أقصى 8 رموز مسموحة من قائمة التجربة. اشتراك كل الرموز قد يتطلب خطة أعلى؛ استجابة subscribe-status وظهور الأسعار هي المرجع الفعلي لكل رمز.
- لا توجد بيانات مباشرة أو مفاتيح مدمجة في المستودع.

## التحقق من الأسواق
- حالة مستقلة لكل رمز: جارٍ الفحص، متاح بانتظار أول سعر، يصل سعر مباشر، رفض/غير متاح، أو سعر قديم.
- لا يُعتبر الرمز متاحاً لمجرد نجاح فتح WebSocket؛ يجب قبول الاشتراك ثم استقبال tick حديث.
- تُرفض القراءات الأقدم من 15 ثانية أو ذات التوقيت غير الصالح.
- عند توقف التحديثات لأكثر من 15 ثانية تظهر حالة السعر القديم وتتوقف صلاحية الإشارة.
- WebSocket يرسل اشتراكاً مجمعاً للرموز، مع heartbeat كل 10 ثوانٍ.

## المؤشرات والمحاكاة
- EMA 5/13 وRSI 7 والزخم على 5 و15 و30 ثانية.
- CALL وPUT لا تصدر إلا عند توافق EMA والزخم وRSI.
- يتطلب تأكيد الإشارة قراءتين جديدتين، مع فترة تهدئة 30 ثانية.
- سجل تجريبي وتقييم حركة السعر بعد 5 و30 ثانية وتصدير CSV.
- لا توجد نسبة نجاح مضمونة. النتائج التجريبية ليست ضماناً للأداء المستقبلي.

## الحدود
- المحرك محاكاة وتحليل فقط؛ لا يتصل بحساب ExpertOption ولا ينفذ صفقات.
- أسعار Twelve Data للسوق الحقيقي لا تستبدل OTC الخاص بالوسيط، ولا تستخدم كأنها نفس التسعير.
- لا تضع كلمة مرور الوسيط أو OTP أو ملفات الجلسة أو مفاتيح الحساب في التطبيق أو GitHub.
