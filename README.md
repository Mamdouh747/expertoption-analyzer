# ExpertOption Analyzer

محلل فني عربي مستقل للاختبار التجريبي وتحليل الأسواق.

## المميزات الحالية
- مؤشرات EMA 5 و EMA 13.
- مؤشر RSI 7 وتحليل الزخم Momentum.
- إشارات CALL و PUT و WAIT.
- فلترة الاتجاه والزخم وقراءة RSI قبل إصدار الإشارة.
- اشتراط تأكيدين متتاليين للإشارة.
- فترة تهدئة 30 ثانية لمنع تكرار الإشارات المتقاربة.
- حد أدنى لقوة توافق المؤشرات قبل تسجيل الإشارة.
- سجل منفصل لتقييم حركة السعر بعد 5 و30 ثانية.
- تصدير سجل الإشارات إلى CSV.
- واجهة عربية متوافقة مع الآيفون.

## وضع التشغيل وحدود النتائج
- المشروع يعمل في وضع المحاكاة فقط.
- الأسعار مولّدة داخل التطبيق وليست أسعار ExpertOption أو OTC مباشرة.
- نسب النجاح المعروضة تصف نتائج المحاكاة المسجلة فقط، ولا تمثل احتمال ربح مستقبلي.
- لا يتصل المشروع بحساب التداول ولا ينفذ صفقات حقيقية.
- لا توجد نسبة نجاح مضمونة؛ يلزم اختبار عدد كافٍ من الإشارات قبل تقييم الأداء.

## الخطوة التالية
اختبار EUR/USD وجمع أول 20 إشارة مكتملة على إطاري 5 و30 ثانية، ثم مراجعة النتائج قبل توسيع الاختبار إلى 200 إشارة.
